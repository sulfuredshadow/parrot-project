# What's the deal?
> A lot actually :3 
* To start of this is a project for those who want but can't have a parrot as a mascot.

### But why?
> Cause it's freaking cool cmon! >"<
---

My intentions are:
  * Make a 3D printed cube style parrot
  * Make it smart (w/LLM)
  * Make it act as an actuall parrot

  ---

>[!IMPORTANT]
> * I'm really going to try my beast to make it posible for local LLM's to be ran on the device for the overall cost of the parrot plus privacy and security reasons, since it kind of looks like a hearing device.
